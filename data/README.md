# data/

数据只分两层：`raw/` 只读，`clean/` 只由代码生成。

## raw/

- 下载或申请来的原始文件，**只读**
- 脚本不得覆盖、就地改名、就地删列
- 在 memo 或 replication README 里记录：来源、下载日、许可、单元键
- **不要编造下载链接**；没有来源就写 `UNVERIFIED` 并说明怎么取得
- 默认不进 git（见根目录 `.gitignore`）

## clean/

- 分析用面板、截面、匹配后样本
- 必须能从 `raw/` + `code/` 重生
- 同样默认不进 git。需要分享时用独立复现包，不要往本仓库塞大文件

## 本目录独立检查项

开始回归前，人工确认：

1. 观察单元与时间键是否唯一
2. 处理变量在谁的层级变化
3. 聚类层级是否与处理层级一致
4. 缺测、重复键、异常合并行数是否写进日志
