# notes/

方法笔记、阅读草稿、自己的思路。比 `papers/` 卡片更自由，也更脏。

## 建议子目录（需要时再建模）

| 路径 | 用途 |
|---|---|
| `notes/methods/` | 自己的脏备忘。收束过的纪律在 `references/methods/`，不要两处各写一套 |
| `notes/pdfs/` | 本机 PDF。默认 gitignore，不要 push |
| `notes/ideas/` | 尚未写成 design memo 的想法 |

## 能力训练怎么记

- 读完一篇：先在 `papers/` 做卡片，细节可留在本目录
- 学到一条方法纪律：写成短笔记，链到某张卡片，不要只写在聊天记录里
- 新想法先写 10 行；要做就升级为 `memos/` 里的 design memo

## 不要放

- 原始数据
- 主回归代码（去 `code/`）
- 已决定采用的识别方案终稿（去 `memos/`）
