# literature-card

把一篇已存在的论文或笔记压成 `papers/` 里一张卡。这是长期能力训练的主入口：练的是「读成设计」，不是写综述。

## 何时用

- 用户放下 PDF、截图、笔记或链接，并说「做卡片 / 读这篇」
- 用户要把零散笔记升级成可检索库存

## 何时不用

- 用户要审计自己的识别 → `identification-audit`
- 用户只要稳健性清单 → `robustness-checklist`
- 没有源文件、用户又不肯口述可核验信息 → 停，不要用记忆补一篇假论文

## 步骤

1. 读源。优先用户指定的 PDF / `notes/` 文件。打不开就停，列出缺什么。
2. 复制 `templates/paper-card.md` 为 `papers/YYYY-venue-slug.md`。venue 未知用 `wp` 或 `notes`。
3. 只填源里写得清的字段。作者、年份、期刊、DOI、系数：源里没有或未核到 → `UNVERIFIED`。
4. 必须写六块：问题、识别、数据、主结果、可攻击点、可复用设计。
5. 「可复用设计」写给未来的自己：能偷的是切断点构造、工具逻辑、样本限制，还是表的讲法。不要写「这篇很重要」。
6. 禁止新增源中未出现的文献和 DOI。
7. 结束时用中文短报：卡片路径、哪些字段 `UNVERIFIED`、建议的下一训（通常是对这张卡跑 `identification-audit`）。

## 质量闸门

- 卡片不是摘要翻译。没有识别与可攻击点，不算完成。
- 主结果必须带出处（表号 / 页码 / 图号）。只有形容词没有数字时，写「作者声称…（无表号，UNVERIFIED）」。
- 已投稿的用户旧稿：除非用户点名，不要为那些文章建卡。

## 产出

- 一个 markdown 文件在 `papers/`
- 不修改 `templates/paper-card.md` 本身
