# RD（一页）

用于 `identification-audit` / `robustness-checklist` / `referee-sim`。不是文献综述。包名只当软件提示，不要编造成引用。

## 先问（不定下来不准写主回归）

1. 排序变量是什么？切断点谁定的、人能不能精确选边？
2. 锐 RD 还是模糊 RD（切断点只改变处理概率）？
3. Estimand 是切断点附近谁的局部效应，还是被写成「全国平均」？
4. 聚类：排序变量层级，还是处理发生的层级？

## 决策树

```
人能否精确操纵排序变量？
├── 能（分数可改、申请可撤）→ 先做密度/操纵检验；过不了就不要因果句
└── 很难
    ├── 锐 RD：切断点附近连续性是核心
    └── 模糊 RD：先报一阶段（切断点 → 处理），主结果按 LATE / 合规者讲
```

带宽、核、多项式阶是**敏感度**，不是识别本身。先写清连续性 + 无精确操纵，再调带宽。

## 最危险的三件事

1. 切断点处组成跳跃（谁能站到切断点边上换了）→ 协变量 / 预定结果也跳
2. 把局部效应写成政策普适结论
3. 模糊 RD 却按锐 RD 解释，或一阶段很弱还在讲因果

## 必须先做（缺一项就标未做）

- 密度 / 操纵检验
- 切断点处协变量（及预定结果）平衡
- 带宽敏感（含常用最优带宽两侧）
- 核或多项式阶敏感
- donut（去掉切断点紧邻）
- 模糊 RD：一阶段 + 弱第一阶段时怎么讲

## 代码提示（需要时再查词典）

Stata 常见：`rdrobust`、`rddensity`、`rdplot`。语法问 [stata-skill](https://github.com/dylantmoore/stata-skill)，不要把手册粘进卡片。

## 写作边界

只允许：「在切断点附近、在这些带宽下」。不允许：「因此该政策整体提高了…」，除非另有外部有效设计。
