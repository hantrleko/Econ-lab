# Identification audit: 2025-jfe-cll-house-prices

审的是 Adelino–Schoar–Severino (JFE 163, 2025) 卡片，对照 `did.md` 和 `rd.md`。只根据 PDF 前约 14 页。仓库里没有他们的回归代码。**不宣布识别成立。**

## Estimand

在 1998–2005 年、10 个 MSA 的单家庭成交里：某年成交价落在「当年 CLL/0.8」之上 $10,000 内的房子（当年较难拿 80% LTV 合规贷），相对落在门槛之下 $10,000 内的房子，其每平方英尺成交价（或特征残差）在「限额生效年」相对「下一年限额上调、两段都能做 80% 合规贷」的差。作者按意图处理讲，不管这笔交易实际怎么贷。

观察单元是成交。处理在全国年调的限额，再通过成交价把房子分到门槛上下。主规格是按年 2×2，再对 8 个年份的系数做 Fama–MacBeth 平均；另有 event-cohort 池化式。聚类：前 14 页用 8 个年系数的截面标准差（并试 Newey–West），不是按处理赋值层（全国-年，或至少 MSA-年）聚类。

## Assumptions (stated vs inferred)

1. **章程年调与本地无关。** 样本期内 CLL 必须按全国单家庭房价指数增速调，11 月宣布次年。源里写了。（stated）
2. **门槛之上融资更差。** 刚过 CLL/0.8 的买家要么 jumbo（前人利差 10–24 bp），要么加大首付/二抵；合规贷更便宜也更好拿。这是识别的核心，源里写了，并说有文献支持。 (stated)
3. **意图处理：用门槛附近所有成交，不按实际贷款类型。** 用来避开 jumbo vs「硬留在合规」的自选。 (stated)
4. **不能做年内锐 RD。** 家庭能选融资方式，排序/处理会被操纵。 (stated)
5. **两年窗口内、门槛上下的房子，若限额不动，每平方英尺价差不应自己变。** 这是这个 2×2 的平行趋势。源里用安慰剂限额和特征控制来挡，没有写成正式 PT 句。 (`UNVERIFIED` / inferred)
6. **11 月宣布不导致成交跨年挪动到足以解释价差。** 源里没审预期。 (`UNVERIFIED` / inferred)
7. **用成交价分组不把结果写进处理；或特征预测价足以修。** 主规格用成交价；稳健用预测价。修能成立是推断。 (`UNVERIFIED` / inferred)
8. **$10,000 带宽里，下一年整段都能做 80% 合规贷。** 脚注：1998–2005 年调幅度盖得住上年 ±$10k。2006–2007 限额没动，砍掉。 (stated)

## Most dangerous threats

1. **用结果给处理分组。** 成交价既是 Y，又决定「门槛上/下」。贵的房子被标成「难贷」，便宜的标成「好贷」，机械上就能出负的「门槛上折价」。特征残差当 Y 只改左边，分组仍用原价。预测价赋值减轻循环，但同年 MSA 特征回归仍吃进当年本地行情。这会把估计往「难贷更便宜」（作者要的符号）推。控制后从 $1.17 掉到 $0.67，可观察质量已经吃掉一半。

2. **谁走进 ±$10k 带宽是选出来的。** 挂牌、出价、谈价都可以往门槛里挤或躲开。作者称成交量没有 bunching、失败申请份额也不像焦点。可是住房供给和买卖双方都能对公开限额做反应；组成一跳，协变量和预定质量也会跳。偏向仍是「门槛上更差/更便宜」，和主结果同向。

3. **独立变异只有大约 8 次全国年调，且人人预见到次年会上调。** 冲击在全国-年，不是成交。Fama–MacBeth 用 8 个系数当「样本」。1998–2005 正是涨价期；11 月已经知道次年 CLL。卖家可以拖到限额上调后再卖门槛上的房子，买家可以抢在上调前买门槛下的。没有事前窗口（每个 cohort 只有 t 和 t+1）。这会把「信贷更容易」和「涨价年里的跨年挪成交」搅在一起；符号仍可能像主结果。

## Must-run diagnostics

对照 `did.md` 和 `rd.md` 的「必须先做」。前 14 页已做的标已做，其余是缺的，不是「也可以」。

- [x] 安慰剂限额放在分布别处（源里声称对不上）
- [x] 作者拒绝年内锐 RD，改意图处理（融资可操纵，这一步对）
- [x] 不用成交价分组的稳健：特征预测价赋值（源里称差不多）
- [x] 特征残差当 Y；按年×MSA 特征回归 + ZIP FE
- [ ] **密度 / 操纵：** 门槛处成交笔数、挂牌价、申请量的密度检验，不能只靠「肉眼没有 bunching」
- [ ] **切断点协变量 / 预定质量平衡：** 面积、房龄、房间、ZIP 均值等在门槛两侧是否跳；与「控制后效应腰斩」对读
- [ ] **带宽敏感：** 除 $10,000 外，试更窄/更宽（仍要求下一年整段可贷），以及常用最优带宽两侧
- [ ] **donut：** 去掉贴着 CLL/0.8 的成交（最容易被焦点和谈价钉住的部分）
- [ ] **模糊 RD 一阶段：** 门槛是否真的改变「一抵正好 80% + 合规」的概率；弱的话主结果不能按利率资本化讲
- [ ] **预期 / 跨年挪动：** 11 月宣布后，12 月 vs 次年 1 月的成交量、构成、门槛上下份额；这是这个设计的事前
- [ ] **聚类 = 赋值层：** 全国-年（或 MSA-年）聚类 / 按年抽块；不要把成交当成独立实验。Fama–MacBeth n=8 要当成「有效样本就是 8 次年调」来讲
- [ ] **对照定义写清：** 每个 cohort 里，t+1 两段都已「好贷」，没有从未处理组；池化式是叠起来的 2×2，不是错时 TWFE。仍要书面说明为何不用从未处理对照（例如更远价格段，或限额未调的 2006–2007 当时间安慰剂）

核 / 多项式是锐 RD 的敏感度。作者不做年内 RD，不单列；带宽和 donut 仍要做，因为设计靠的就是门槛附近。
